# Задача 03. Минимальная тестовая основа

## Промпт

Добавь минимальную систему автоматических тестов для чистой бизнес-логики. Выбери совместимый с текущим TypeScript/Next.js инструмент с минимальным количеством зависимостей. Не тестируй разметку и очевидные реализации.

Покрой только критические правила: количество ночей, базовые и сезонные цены, агентская наценка, пересечение дат, нормализация параметров проживания, переходы статусов заявки и вычисление ограничений подписки. Если функцию невозможно тестировать без базы или Next.js, сначала извлеки чистую функцию с минимальным изменением API.

Добавь один понятный npm script для целевого запуска тестов и краткую инструкцию разработчику.

## Готово, когда

- критические правила запускаются локально одной командой;
- тесты воспроизводят границы диапазонов и недопустимые переходы;
- тесты не дублируют JSX и внутреннее устройство функций.

## Проверки

- новый целевой test script
- npx --no-install tsc --noEmit --incremental false
- ESLint только для измененных TS/TSX-файлов
