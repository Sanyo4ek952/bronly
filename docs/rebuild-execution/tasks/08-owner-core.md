# Задача 08. Основной сценарий владельца

## Промпт

Пересобери на новой UI-основе основной путь владельца: вход, онбординг, кабинет, список объектов и самостоятельных номеров, создание и редактирование объекта/номера, фотографии, базовая и сезонная цена, занятые даты и получение публичной ссылки.

Работай вертикальными срезами. После каждого завершенного экрана удаляй только его старые CSS-селекторы. Разделяй загрузку данных, server actions и UI. Большие компоненты дели по ответственности, если это уменьшает сложность и дает осмысленные границы. Не меняй бизнес-правила PRD.

## Готово, когда

- новый владелец проходит путь до публичной ссылки;
- объект и самостоятельный номер поддерживаются одинаково полно;
- формы показывают понятные ошибки и успешные состояния;
- интерфейс работает на телефоне и desktop;
- старые стили этих экранов удалены.

## Проверки

- целевые тесты затронутой бизнес-логики
- TypeScript
- ESLint измененных файлов
- browser smoke-test полного owner flow
- production build после завершения всего среза
