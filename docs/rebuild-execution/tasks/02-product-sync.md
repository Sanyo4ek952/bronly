# Задача 02. Синхронизация продукта

## Промпт

Синхронизируй canonical PRD с уже принятыми решениями из decision-log. Перенеси только явно зафиксированные решения, которых еще нет или которые описаны неоднозначно: стабильная публичная ссылка агента, самостоятельные номера и персональные приглашения с ручным реферальным продлением. Не придумывай новые правила.

Проверь согласованность ролей, заявки, коллекций, подписки, цен и терминологии между prd.md, decision-log.md и product-boundaries.md. Устрани только документальные расхождения, для которых решение уже принято. Если обнаружен настоящий продуктовый конфликт без принятого решения, соблюдай conflict protocol.

## Готово, когда

- PRD содержит все принятые решения из журнала;
- краткие документы не противоречат PRD;
- порядок последующей реализации однозначно опирается на разделы PRD.

## Проверки

- npm run check:encoding
- ручная сверка терминов по docs/product/terminology.md
