# Задача 14. Рефералы и админка

## Промпт

Доведи персональные приглашения и ручное реферальное продление по decision-log. Invite должен сохранять пригласившего и ожидаемую роль. Milestone владельца — первый объект или самостоятельный номер; milestone агента — первое активное сотрудничество. Создавай одно pending-вознаграждение, не продлевай подписку автоматически.

В админке реализуй безопасную очередь подтверждения или отклонения, переход к подпискам пользователя и ручное продление на 10 дней для owner/agent subscription contexts пригласившего. Проверь также существующие административные ограничения публичных страниц и объектов.

## Готово, когда

- invite и milestone идемпотентны;
- бонус получает только пригласивший после ручного решения;
- обычный пользователь не может назначить admin или подтвердить бонус;
- административные действия имеют понятный результат и не выполняются дважды.

- целевые тесты referral lifecycle
- TypeScript
- ESLint измененных файлов
- RLS/admin smoke-tests
- browser smoke-test приглашения и очереди
- production build
