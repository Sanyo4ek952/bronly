# Задача 12. Коллекции

## Промпт

Доведи коллекции владельца и агента: создание, название для гостя, бессрочная жизнь до архивации, добавление объектов и отдельных номеров, публичная ссылка, статистика открытия и заявка только на конкретный room_id.

Если добавлен объект целиком, публичная страница должна предложить его номера. Показывай актуальную цену при открытии и сохраняй snapshot при заявке. Для агентской коллекции используй контакт и итоговую цену агента. Не добавляй общий каталог или рекомендации.

## Готово, когда

- owner и agent создают разрешенные коллекции;
- архивная или недоступная коллекция не принимает заявки;
- контекст источника и агентская цена сохраняются;
- статистика открытия не создает очевидные дубли при одном просмотре.

## Проверки

- целевые тесты collection context и заявки
- TypeScript
- ESLint измененных файлов
- browser smoke-test owner и agent коллекций
- production build
