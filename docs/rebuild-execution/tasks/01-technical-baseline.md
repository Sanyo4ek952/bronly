# Задача 01. Техническая база

## Промпт

Зафиксируй проверяемую техническую базу Bronly перед переработкой. Прочитай AGENTS.md и продуктовые документы. Проверь git status, структуру src, package.json, конфигурацию TypeScript, ESLint, Tailwind/PostCSS, Next.js и Supabase migrations. Используй Graphify для scope src.

Не исправляй продуктовые функции на этом этапе. Зафиксируй в STATUS.md фактические команды проверки, состояние сборки, крупные файлы и известные архитектурные проблемы. Убедись, что проект можно воспроизводимо установить и проверить по существующим инструкциям; если инструкция отсутствует или неверна, обнови только инженерную документацию.

## Готово, когда

- известны рабочие команды lint, TypeScript, build и encoding;
- зафиксированы крупные источники долга без массовой переработки;
- Graphify-граф src актуален;
- изменения пользователя сохранены.

## Проверки

- npm run lint
- npx --no-install tsc --noEmit --incremental false
- npm run build
- npm run check:encoding
