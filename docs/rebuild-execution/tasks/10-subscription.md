# Задача 10. Подписка

## Промпт

Доведи подписочную модель из PRD: trial, active, grace и expired, ручное продление администратором и лимит активных номеров. Определи поведение кабинета, публичной страницы и приема заявок строго по принятой документации.

Сделай вычисление статуса тестируемым и единым для owner и agent contexts. Устрани скрытые изменения статуса во время обычного чтения, если они создают непредсказуемые побочные эффекты; при необходимости выдели явную синхронизацию. UI должен объяснять пользователю текущее ограничение и действие для продолжения.

## Готово, когда

- переходы статусов и даты проверены тестами;
- лимит активных номеров нельзя обойти через разные формы;
- public/request ограничения согласованы;
- ручное продление работает и журналируется.

## Проверки

- целевые тесты подписки
- TypeScript
- ESLint измененных файлов
- owner/agent subscription smoke-tests
- production build
