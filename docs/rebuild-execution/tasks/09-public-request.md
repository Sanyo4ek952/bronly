# Задача 09. Публичная страница и заявка гостя

## Промпт

Пересобери публичную страницу владельца и путь гостевой заявки на Tailwind. Гость должен видеть только варианты конкретного владельца, фильтровать по датам, гостям и комнатам, выбирать конкретный room_id, видеть актуальную цену и отправлять заявку.

Сервер повторно проверяет публикацию, видимость, подписку, вместимость, занятость, цену и принадлежность номера странице. Заявка сохраняет ценовой snapshot. Успешный экран использует терминологию заявки и не обещает подтвержденное проживание.

## Готово, когда

- путь публичная ссылка → конкретный номер → заявка работает;
- неподходящие варианты объясняются, но страница не превращается в общий каталог;
- сервер не доверяет цене и контексту из формы;
- владелец видит новую заявку с правильным источником и snapshot.

## Проверки

- целевые тесты заявки, цены и доступности
- TypeScript
- ESLint измененных файлов
- browser smoke-test успешного и ошибочного guest flow
- mobile visual check
- production build
