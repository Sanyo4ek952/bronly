# Задача 11. Агентский контур

## Промпт

Доведи агентский сценарий по PRD и decision-log: профиль и стабильная публичная ссылка формата /a/ag_xxxxxx, предложение владельцу, принятие или отклонение, активное сотрудничество, read-only календарь, агентская витрина, агентская цена, получение заявки, передача владельцу и запрос завершения.

Проверь права на каждом переходе. Агент не редактирует объект, номер, фото, базовую цену или календарь владельца. Контакты на агентской странице принадлежат агенту. Legacy slug только редиректит на канонический URL.

## Готово, когда

- весь агентский путь работает от предложения до completed;
- только владелец ставит completed;
- источник и цена агентской заявки сохраняются корректно;
- чужие данные доступны агенту только в разрешенном read-only объеме.

## Проверки

- целевые тесты переходов и агентской цены
- TypeScript
- ESLint измененных файлов
- RLS smoke-tests
- browser smoke-test owner + agent flow
- production build
