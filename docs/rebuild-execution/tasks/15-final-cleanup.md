# Задача 15. Очистка и финальная проверка

## Промпт

Проведи финальный аудит Bronly после завершения предыдущих задач. Найди оставшиеся импорты против направления слоев, крупные компоненты без ясной ответственности, неиспользуемые mock-данные, пустые catch, небезопасные ручные приведения типов, дубли UI и оставшиеся br-* потребители.

Удаляй код и CSS только после доказательства, что потребителей нет. Оставь в globals.css базовые правила, тему и действительно глобальные стили. Обнови component-index, инженерную документацию и Graphify-граф.

Проведи полный end-to-end smoke-test ролей owner, guest, agent и admin. Не публикуй и не меняй production без отдельного запроса пользователя.

## Готово, когда

- основной owner/guest flow полностью работает;
- agent, collections, subscription, notifications, referrals и admin соответствуют PRD;
- отсутствуют ложные успехи и скрытые fallback на реальные сценарии;
- старые стили не управляют мигрированными экранами;
- документация соответствует реализации.

- все тесты

- npm run build

- RLS smoke-tests при доступной локальной базе
- browser smoke-test критических сценариев и mobile viewport
