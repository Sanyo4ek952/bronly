# Задача 13. Уведомления и PWA

## Промпт

Доведи in-app, Telegram и PWA push уведомления для событий из PRD. Создание основного бизнес-события не должно откатываться из-за сбоя вторичного канала уведомления, но сбой доставки должен быть видим в диагностике и статусе delivery.

Проверь разрешения браузера, регистрацию service worker, повторные подписки и отключение канала. Не добавляй SMS. Уведомления должны вести в правильный owner или agent экран и не раскрывать лишние данные.

## Готово, когда

- события создают in-app запись;
- Telegram и push имеют отслеживаемый результат доставки;
- отказ одного канала не создает дубликат основной заявки;
- PWA устанавливается и имеет корректный manifest/service worker.

## Проверки

- целевые тесты fan-out и идемпотентности
- TypeScript
- ESLint измененных файлов
- browser PWA smoke-test
- production build
