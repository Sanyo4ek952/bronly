# Задача 07. UI-основа на Tailwind CSS v4

## Промпт

Создай последовательную UI-основу Bronly на Tailwind CSS v4. Используй существующие дизайн-токены и терминологию. Прочитай применимые UI skills, проверь src/shared/ui и component-index до создания новых компонентов.

Приведи к единому API Button/ButtonLink, поля форм, Panel, InlineNotice, StatusPill, Tabs, BottomSheet и каркас кабинета. Определи состояния hover, focus, disabled, loading и error. Сохрани доступность и mobile-first поведение.

Не удаляй весь globals.css сразу. Перенеси стили только потребителей, затронутых этой задачей, после чего удали ставшие неиспользуемыми дублирующие определения. Не добавляй новые глобальные feature-классы.

## Готово, когда

- основные примитивы используют Tailwind;
- токены и состояния единообразны;
- новые экраны можно собирать без новых br-* классов;
- component-index соответствует коду.

## Проверки

- TypeScript
- ESLint измененных файлов
- production build
- визуальная проверка примитивов на узком и широком viewport
- npm run check:encoding
