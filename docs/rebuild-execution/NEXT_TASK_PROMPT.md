# Промпт передачи следующему чату

Этот текст передается в новый чат с подстановкой номера и имени файла задачи:

Продолжи явно порученную пользователем последовательную переработку Bronly. Это отдельный чат только для задачи TASK_NUMBER из файла TASK_FILE.

Пользователь явно разрешил после успешного завершения каждой задачи автоматически создавать следующий отдельный чат для очередной `pending`-задачи без дополнительного подтверждения. Это разрешение действует на всю последовательную цепочку из `STATUS.md`, но не разрешает публикацию, необратимые действия или расширение продуктового scope.

Работай в текущем локальном checkout сохраненного проекта. Прочитай AGENTS.md и обязательные документы, затем docs/rebuild-execution/README.md, MASTER_PROMPT.md, STATUS.md и TASK_FILE. Не перечитывай файлы других завершенных задач без конкретной необходимости.

Выполни ровно эту задачу, проведи указанные в ней проверки и обнови STATUS.md. После успешного завершения создай отдельный новый чат для следующей pending задачи по протоколу MASTER_PROMPT.md. Не выполняй следующую задачу в этом чате.
