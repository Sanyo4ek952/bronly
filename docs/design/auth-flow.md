# Общая оболочка авторизации Bronly

Маршруты: `/login`, `/register`, `/check-email`, `/forgot-password`, `/reset-password`, `/welcome`, `/invite/[token]`

Этот общий визуальный контракт был подготовлен до восстановления исходной очереди D29–D59. Он не заменяет отдельные задачи D50–D53 и D57–D59, а фиксирует уже внедрённое shared-основание для них.

Все маршруты используют `AuthShell`, `Panel`, `BrandLogo`, поля, notices и общие CTA. Desktop-композиция разделяет вводный контекст и основное действие; на mobile продуктовые ориентиры скрываются, форма остаётся одноколоночной. Loaders, redirects, query-параметры, server actions, роли и invite token не менялись.

Representative login state просмотрен на `1440 × 900`, `390 × 844` и `320 × 720`. Отдельные route-specific состояния должны быть проверены в своих задачах очереди.
