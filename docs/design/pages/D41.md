# D41 — Ручные проверки администратора

Маршрут: `/admin/reviews`

Статус: route-specific аудит подтверждает существующий mobile-first redesign.

## Продуктовая опора

`docs/product/prd.md`, §§8 и 10: после целевого действия referral reward остаётся на ручном подтверждении администратора; автоматическое начисление запрещено.

## Решение и QA

`AdminReviewsPage` показывает пригласившего, приглашённого, milestone, контекст роли и действия подтвердить/отклонить. На `1440 × 900`, `390 × 844` и `320 × 720` metadata становится одним столбцом, а actions остаются доступными над bottom navigation. Feedback, empty queue и server actions не меняются.
