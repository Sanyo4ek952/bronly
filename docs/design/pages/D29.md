# D29 — Подборки агента

Маршрут: `/agent/dashboard/collections`

Статус: реализовано через общий collections dashboard; route-specific контракт восстановлен из исходной очереди.

## Продуктовая опора

- `docs/product/prd.md`, §§4.2, 5.5–5.6 и 8.1 — агент создаёт персональные подборки из собственных вариантов и вариантов по активным сотрудничествам.
- `docs/product/prd.md`, §§15–17 — экран не превращается в общий каталог и не добавляет автоматическое подтверждение заявки.

## Решение по переиспользованию

Маршрут использует общий `CollectionListSection` с agent loaders и actions. В D06 был создан opt-in owner layout, а default agent layout сохранён специально до D29. Реализация D29 включает существующий плоский list presentation без копии карточек или фильтров. Данные, пагинация, публикация, архивирование и ограничения подписки не меняются.

## Композиция

- открытый header с одним CTA создания подборки;
- компактная сводка `всего / активные / открытия` без отдельных stat cards;
- двухколоночный список на desktop и один столбец на mobile;
- статус, название, количество вариантов и открытия остаются внутри одной поверхности карточки;
- empty и ограниченные состояния используют существующие shared-компоненты.

## QA

Representative active-list state проверен в макете на `1440 × 900`, `390 × 844` и `320 × 720`. Production route использует уже внедрённый `layout="owner-list"` как общий presentation-вариант; agent loader, actions и ссылки сохранены.
