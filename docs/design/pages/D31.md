# D31 — Новая подборка агента

Маршрут: `/agent/dashboard/collections/new`

Статус: route-specific контракт; shared implementation уже внедрён.

## Продуктовая опора

`docs/product/prd.md`, §§5.6 и 8.1: агент создаёт пустую персональную подборку, затем добавляет доступные варианты и отправляет гостю прямую ссылку. Создание не публикует общий каталог и не подтверждает проживание.

## Переиспользование

`CollectionCreateSection` обслуживает owner и agent actions. D31 использует существующий `owner-create` presentation, сохраняя agent breadcrumb, `createAgentCollectionAction`, query feedback и последующий redirect. Копия формы не создаётся.

## Композиция

- открытый header и breadcrumb;
- одна основная поверхность с двумя полями;
- спокойный блок «Что дальше» внутри той же поверхности, без второй карточки;
- footer с primary create и secondary back;
- на mobile блоки и действия складываются в один столбец.

## QA

Форма проверена на `1440 × 900`, `390 × 844` и `320 × 720`. Поля, пояснения и CTA переносятся без собственной минимальной ширины. Server action и ограничения длины полей не изменены.
